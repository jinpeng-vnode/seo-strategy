## 根因分析

### 1. 容器未部署

```
$ docker ps -a | grep -E "calculator|compress|excalidraw|password|qrcode|json-tools|regex|color"
（无结果 - 容器完全不存在）
```

虽然项目代码存在于 `/Users/jinpeng/projects/` 目录下，且 Traefik 的 HTTP Provider（VNode 后端）中配置了路由规则，但实际容器从未启动或已被移除。

### 2. DNS 解析正常但无法响应

- DNS 解析：*.todonot.com → 162.251.93.118（MPTCP 网关出口 IP）
- 流量路径：用户 → DNS → MPTCP 网关 → Traefik → 容器（不存在）→ 502

### 3. Google 无法收录

由于站点持续返回 502，搜索引擎爬虫无法抓取任何内容：
- Googlebot 访问 → 502 → 不收录
- 其他爬虫（从日志看有定期 robots.txt 请求）→ 502 → 放弃
