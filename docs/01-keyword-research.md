## 2. 长尾关键词挖掘

### 2.1 挖掘方法论

**关键词公式**：`[动作] + [对象] + [限定条件] + [修饰词]`

示例：
- compress + png + to 100kb + online free
- calculate + BMI + for women + metric
- create + flowchart + online + no signup
- generate + temp email + with custom domain + free

**低竞争高流量判断标准**：
- 搜索结果首页有论坛帖子/低质量页面 = 低竞争
- 搜索结果首页全是大站 = 高竞争
- 包含具体数值/场景的长尾词通常竞争更低

### 5.1 第一批落地页（第1周）

- image-compress: 首页 + compress-png-to-100kb + compress-image-to-50kb + compress-jpg-to-20kb + compress-photo-for-passport
- calculator: 首页 + bmi-calculator + age-calculator + tip-calculator + gpa-calculator
- excalidraw-hub: 首页 + whiteboard + flowchart-maker + wireframe-tool + architecture-diagram
- temp-mail: 首页 + disposable-email + custom-domain + email-generator + temp-inbox

### 5.2 第二批落地页（第2-3周）

每个工具站再扩展 10 个页面，覆盖所有 ⭐⭐⭐ 关键词。

### 5.3 持续扩展（第4周+）

- 监控 Google Search Console 中的实际搜索词
- 发现新的长尾词机会
- 根据排名数据调整页面内容
- 添加多语言版本（日语、韩语、西班牙语优先）

### 5.4 关键词密度建议

- Title: 包含完整目标关键词
- H1: 包含目标关键词的自然变体
- 首段: 前100字内出现关键词
- 正文: 关键词密度 1-2%
- URL: 包含关键词（用连字符分隔）
- Alt text: 图片描述中包含关键词
- Meta description: 包含关键词 + CTA

## 6. 竞争分析总结

### 6.1 我们的优势

1. **多工具矩阵**：4个工具站互相引流，形成内链网络
2. **长尾策略**：避开头部关键词，专攻低竞争长尾
3. **Programmatic SEO**：批量生成针对性落地页
4. **技术优势**：现代前端框架，Core Web Vitals 分数高

### 6.2 我们的劣势

1. **新域名**：没有域名权威，需要时间积累
2. **无品牌认知**：需要通过外链和社区建立品牌
3. **子域名结构**：权重不如子目录集中

### 6.3 突破策略

1. **先打长尾**：用 "compress png to 100kb" 这类精确长尾词快速获得排名
2. **场景化内容**：为每个使用场景创建专属页面（for passport, for WhatsApp 等）
3. **多语言覆盖**：英语竞争激烈时，先打日语/韩语/西班牙语市场
4. **工具互链**：4个子站之间建立相关性链接，提升整体权重
